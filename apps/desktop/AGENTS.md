# apps/desktop — main process / IPC notes

- **Appium server lifecycle:** `main/handlers/appium.handler.ts` spawns/kills the Appium CLI (`appium --port`). Resolves the bin + a Node-aware PATH via login shell (Electron GUI apps don't inherit shell PATH). `freePort()` kills orphans on the port before spawn; `killAppiumOnQuit()` runs on `before-quit`. IPC: `APPIUM_START/STOP/STATUS/LOG`, `APPIUM_DRIVERS_GET`, `APPIUM_DRIVER_INSTALL`. Logs streamed to renderer (ANSI-stripped) via `APPIUM_LOG`.
- **Appium live inspector session:** `main/handlers/appium-session.handler.ts` holds one live WDA session (independent of test runs) via raw `fetch` to the Appium server. IPC: `APPIUM_SESSION_START/STOP/STATUS/SOURCE/TAP/SWIPE/DEVICES`. Tap/swipe take normalized 0–1 coords → multiplied by device `window/rect`, sent as W3C pointer actions. Devices listed via `xcrun simctl` (iOS) + `adb devices` (Android). Session torn down on quit.
- **Detached inspector window:** `index.ts` `openInspectorWindow()` opens a second `BrowserWindow` loading the renderer with `#inspector` hash (see `main.tsx` routing). Shares the main-process session singleton. IPC: `APPIUM_INSPECTOR_OPEN`.
- **Engine Appium platform:** `engine.handler.ts` injects `APPIUM_HOST/PORT` into profile vars for `platform: 'appium'` test cases and calls `ensureAppiumRunning()` when `appium.autoStart` is set.
- **Custom Playwright browsers path:** `execution.browsersPath` setting (core `app-settings.ts`) → `engine.handler.ts` `applyBrowsersPath()` sets `PLAYWRIGHT_BROWSERS_PATH` before each run-case/run-suite. Fixes web runs failing at 0ms when GUI-launched Electron doesn't inherit the shell env and browsers live in a custom/external dir. UI: `settings/sections/ExecutionSection.tsx`.
- **API test runner:** `platform: 'api'` test cases route to `ApiAdapter` (pure Node `fetch`, no browser). Runner routing fix: `testCase.runner === 'api'` now implies `platform: 'api'` when `testCase.platform` is absent. `ExecutionHelpers` has `setVariable` for cross-step variable passing. New keywords in `engine/keywords/defs/api.ts`: `extract-body`, `set-auth-bearer`, `set-auth-basic`, `assert-header`, `assert-status-range`, `assert-response-time`, `set-variable`, `log-response`. `ApiSession.variables` stores extracted values accessible via `{{varName}}` interpolation in later steps.
- **Profile API Config:** `ProfileSchema` extended with `api?: { baseUrl, defaultHeaders, auth }`. `ApiAdapter.start()` seeds `session.baseUrl`/`session.defaultHeaders` from `profile.api` (fallback: `variables.BASE_URL`). Auth (bearer/basic/api-key) auto-applied to `defaultHeaders`. `EnvManagerDialog` gains "API Config" tab via `ApiProfileForm.tsx`. IPC: `ENV_READ_PROFILE` (full profile), `ENV_WRITE` payload extended with `api` field. `useTestCaseRun` reads full profile and passes `profileApi` in `ENGINE_RUN_CASE` payload.
