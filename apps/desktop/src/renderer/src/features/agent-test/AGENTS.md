# agent-test feature

## Components

- **AgentTestView:** Root tab container. Two sub-tabs: Test Runner (default) + Agent Setup.
- **AgentSetupTab:** Config form — model provider/ID, MCP server toggle (Playwright), skill toggles (browser/playwright), system.md + agents.md editors. "Save Config" writes `.mcp.json`, `.agents/`, `.agents/skills/`, and `agent-tests/` dirs to project root.
- **TestRunnerTab:** Collapsible test input (URL, feature, test data, account/env, extra instructions) + chat interface reusing `agent/MessageList` and `agent/ChatInput`. "Run Agent Test" builds a prompt from inputs and sends via `AGENT_CHAT` IPC.
- **store.ts:** Zustand store for `AgentTestConfig`, `RunInput`, chat messages, send state. Separate from the main `agent` store so agent-test chat history is independent.
- **types.ts:** `AgentTestConfig`, `RunInput`, `ModelProvider`.

## Project files generated by Save Config

```
<project>/
├── .mcp.json                      # Playwright MCP server config
├── .agents/
│   ├── system.md                  # agent system instructions
│   ├── agents.md                  # agent role/capability description
│   └── skills/
│       ├── browser.md             # browser interaction skill
│       └── playwright.md          # JKAuto test generation skill
└── agent-tests/
    ├── traces/
    ├── generated-cases/
    └── reports/
```
